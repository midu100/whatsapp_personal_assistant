# Portfolio

## Air BnB - Property booking platform
Airbnb এর ধাঁচে একটা full-stack property booking platform। Host রা property list করতে পারে, guest রা search করে filter দিয়ে খুঁজে booking দিতে পারে। Property তে multiple image upload হয় Cloudinary তে। Review ও rating system আছে। Frontend React + Redux Toolkit Query, backend Express + MongoDB। Role based access - admin, host আর সাধারণ user এর আলাদা permission। GitHub: github.com/midu100/Air_Bnb

## E-commerce Full Stack
একটা সম্পূর্ণ e-commerce website। Product ও category management, cart, checkout, order tracking, user authentication, admin dashboard - সবকিছু আছে। Product list এ pagination, search আর price/newest অনুযায়ী sorting। Admin panel থেকে product যোগ করা, stock আর order status update করা যায়। GitHub: github.com/midu100/E-commece-FullStack

## Kazir Haat - Online marketplace
বাংলাদেশি ক্লায়েন্টদের জন্য বানানো একটা online shop। Client আর server আলাদা দুটো repo। SSLCommerz payment gateway integrate করা - bKash, Nagad, card সব দিয়ে payment নেওয়া যায়। সাথে cash on delivery option। Order confirmation email যায় nodemailer দিয়ে। Server টা Render এ deploy করা। GitHub: github.com/midu100/Kazir_Haat_Client আর github.com/midu100/Kazir_Haat_server

## Chat Web Application
Real-time messaging application। socket.io দিয়ে instant message delivery, online/offline status, typing indicator। WebRTC দিয়ে audio ও video call এর signaling। Message history MongoDB তে রাখা। JWT দিয়ে authentication, token cookie তে। GitHub: github.com/midu100/ChatWebApplication

## E-commerce with Next.js
Next.js এর App Router দিয়ে বানানো e-commerce। Route group দিয়ে auth, admin আর shop এর অংশ আলাদা করা। SEO এর জন্য server-side rendering আর dynamic metadata। Middleware দিয়ে protected route handle করা হয়েছে। SEO গুরুত্বপূর্ণ হলে এই ধরনের setup ই recommend করি। GitHub: github.com/midu100/Ecommerce-Next.js-
