# FAQ

## আপনি কী কী কাজ করেন?
Website আর web application বানাই - landing page, business website, e-commerce, admin dashboard, custom web app। Frontend থেকে backend, database, API, admin panel, deployment পর্যন্ত পুরোটা একাই করি।

## কোন technology তে কাজ করেন?
Frontend এ React আর Next.js, styling এ Tailwind CSS। Backend এ Node.js, Express আর MongoDB। এটাকেই MERN stack বলে। Real-time কিছু লাগলে socket.io।

## WordPress দিয়ে করে দিতে পারবেন?
না, WordPress এ কাজ করি না। আমি custom code এ website বানাই - এতে site অনেক দ্রুত হয়, যা খুশি customize করা যায়, আর plugin এর উপর নির্ভর করতে হয় না। তবে খুব সাধারণ blog টাইপ কিছু হলে WordPress ই সস্তা পড়বে, সেটা সরাসরি বলে দিই।

## Mobile app বানাতে পারবেন?
Native Android বা iOS app (Java, Kotlin, Swift) বানাই না। তবে website টা mobile এ পুরোপুরি responsive হয়, ফোনেও app এর মতোই দেখায়।

## Design ও কি আপনি করবেন?
সাধারণ ও পরিষ্কার UI আমি নিজেই বানিয়ে দিতে পারি। তবে ক্লায়েন্টের নিজের Figma design থাকলে সেটা থেকে pixel-perfect করে বানিয়ে দেওয়া হয় - এটাই সবচেয়ে ভালো হয়।

## Figma design থেকে কাজ করতে পারবেন?
হ্যাঁ, Figma থেকে pixel-perfect frontend বানানো নিয়মিত করি। Design থাকলে কাজ দ্রুত হয় আর খরচও একটু কম পড়ে।

## কত সময় লাগবে?
কাজের আকারের উপর নির্ভর করে। ছোট landing page ৭-১২ দিন, business website ২-৩ সপ্তাহ, e-commerce ৪-৮ সপ্তাহ। Requirement বিস্তারিত জানার পর নির্দিষ্ট করে বলা যায়।

## দাম কত?
Project এর ধরন আর কী কী feature লাগবে তার উপর নির্ভর করে। কী বানাতে চান সেটা জানালে একটা আনুমানিক range বলে দেওয়া যায়।

## Payment কীভাবে নেন?
৫০% advance, বাকি ৫০% delivery এর সময়। বড় project হলে milestone অনুযায়ী ভাগ করে নেওয়া যায়। দেশের ভিতরে bKash, Nagad বা bank transfer।

## Advance না দিয়ে কাজ শুরু করা যাবে?
না, advance ছাড়া কাজ শুরু করা হয় না। এটা দুই পক্ষের নিরাপত্তার জন্যই। তবে advance এর আগে requirement নিয়ে বিস্তারিত আলোচনা আর estimate - সবই free।

## কাজ পছন্দ না হলে টাকা ফেরত পাব?
কাজ milestone এ ভাগ করা থাকে, প্রতিটা ধাপে দেখিয়ে feedback নেওয়া হয় - তাই শেষে গিয়ে পছন্দ না হওয়ার ঝুঁকি প্রায় থাকেই না। Refund এর নির্দিষ্ট শর্ত নিয়ে সরাসরি কথা বলে নেওয়া ভালো।

## Source code পাব?
হ্যাঁ। Final payment হয়ে গেলে পুরো source code আপনার। GitHub repo transfer করে দেওয়া হয়।

## Hosting আর domain এর খরচ কি এর মধ্যে ধরা?
না, hosting আর domain আলাদা খরচ, সেটা আপনি নিজে দিবেন। তবে কোথা থেকে নেওয়া ভালো আর কত খরচ পড়বে সেটা বলে দেওয়া হয়, আর setup ও করে দেওয়া হয়।

## Delivery র পর কোনো সমস্যা হলে?
Delivery র পর ১৪ দিন পর্যন্ত bug fix free। এরপর চাইলে monthly maintenance নেওয়া যায়।

## আমার আগের website টা ঠিক করে দিতে পারবেন?
পারি, যদি সেটা React/Next.js/Node এ বানানো হয়। প্রথমে code টা দেখে বলতে পারব কী অবস্থা আর কত সময় লাগবে। WordPress বা PHP এর site হলে সাধারণত নেই না।

## আমার site টা খুব slow, ঠিক করা যাবে?
হ্যাঁ, performance optimization করি - image optimize, code splitting, unnecessary re-render কমানো, database query optimize। আগে site টা দেখে সমস্যা কোথায় সেটা বলতে পারব।

## SEO করে দিবেন?
Technical SEO টা করে দেওয়া হয় - meta tag, sitemap, দ্রুত load, mobile responsive, server-side rendering। SEO খুব গুরুত্বপূর্ণ হলে Next.js এ বানানোর পরামর্শ দিই। তবে content লেখা বা backlink তৈরি - সেটা আমার কাজ নয়।

## Payment gateway লাগাতে পারবেন?
হ্যাঁ। বাংলাদেশে SSLCommerz লাগিয়ে দিই - এতে bKash, Nagad, card সবই একসাথে চলে। দেশের বাইরের জন্য Stripe।

## Admin panel থাকবে?
হ্যাঁ, প্রায় সব project এই admin panel দেওয়া হয় - যাতে আপনি নিজেই product, order, user, content সব manage করতে পারেন। কোনো কিছু বদলাতে বারবার developer এর কাছে আসতে না হয়।

## আপনি কি একা কাজ করেন নাকি team আছে?
আমি নিজেই পুরো কাজটা করি - এতে quality এক রকম থাকে আর যোগাযোগে ভুল বোঝাবুঝি কম হয়।

## আগের কাজের নমুনা দেখতে পারি?
অবশ্যই, GitHub link আর live demo দুটোই দেখানো যায়। কোন ধরনের কাজ দেখতে চান বললে সবচেয়ে কাছাকাছি project টা পাঠিয়ে দিচ্ছি।

## বাংলায় কথা বলা যাবে?
হ্যাঁ, বাংলা ইংরেজি দুটোতেই স্বচ্ছন্দ। আপনি যেভাবে সহজ মনে করেন সেভাবেই বলুন।

## এখনই কাজ শুরু করতে পারবেন?
একসাথে সীমিত কয়েকটা project নিই যাতে প্রতিটাতে ঠিকমতো সময় দেওয়া যায়। কবে শুরু করা যাবে সেটা এখনকার অবস্থা দেখে বলতে হবে।

## Call এ কথা বলা যাবে?
হ্যাঁ, সাধারণত শনি থেকে বৃহস্পতি রাত ৮টা-১১টার মধ্যে। কোন সময়টা আপনার জন্য সুবিধা হবে বললে ঠিক করে নেওয়া যায়।
